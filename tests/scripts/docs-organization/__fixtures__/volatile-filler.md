# fastgrid

fastgrid is a battle-tested grid engine with 1.2k stars on GitHub, used by
50+ teams in production.

## Highlights

- 3x faster than the leading alternative.
- 94% coverage across 1,200 unit tests.
- About ~8k LOC, with only 4 dependencies.
- It currently supports 12 languages and 40+ built-in checks.

## Status

As of v2.1, fastgrid now supports streaming. Plugin hosting is coming soon,
and 30 contributors have landed 2,400 commits so far.

Built on markdown-it 14.1.0; install it with fastgrid@2.0.0-rc1.

```bash
fastgrid run --workers 8   # 147 tests run here, but this is code
```
